# Asistente-de-ruta-academica
Muchos estudiantes no saben qué materias se les bloquean cuando pierden o retiran una asignatura, cuáles pueden matricular ni cómo se acumulan sus créditos y su promedio. Este trabajo modela el plan de estudios de Ingeniería de Sistemas y Computación de la Universidad del Norte como un grafo dirigido acíclico
